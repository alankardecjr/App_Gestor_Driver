# Paleta oficial da UI vs-2.0

Paleta congelada junto com as telas aprovadas da branch `vs-2.0`.

## Direção visual

- Base neutra, clara ou escura.
- Verde petróleo para ações, receitas, lucro e Histórico.
- Azul petróleo para Carteira, distância e métricas de percurso.
- Ocre/marrom para despesas e consumo.
- Vermelho queimado somente para Fechar, custos negativos e alertas.
- Ícones brancos sobre fundos coloridos.
- Sem gradiente roxo e sem roxo como cor de ação.
