================================================================================
0. COMO LER ESTE ARQUIVO
================================================================================

Cada tela tem:
  - o que faz
  - esboço (texto)
  - o que entra de cada inspiração
  - o que NÃO entra
  - ponto para você marcar: [ ] ok   [ ] ajustar (escreva o que)

Três fontes (ideia, não clone):
  A) Gigu — compacta 3 linhas, cards de histórico, valor grande, rota ● / ■
  B) Líder da loja (teal/limão) — notificação magra, botões de mapa, config em lista
  C) Gestor Beta — selo, classificação na borda, abas Uber/99/inDrive, lucro/gasto/litros
     do combustível atual, histórico só no aceite


================================================================================
1. O QUE FICA IGUAL À BETA (não negociar na 2.0)
================================================================================

- O Gestor não tem botão Aceitar / Recusar.
- Histórico só grava quando o aceite foi identificado na Uber, 99 ou inDrive.
- Classificação = faixas de R$/km (CALIBRAR) → cor da borda.
- Cálculos de litros / gasto / lucro = só combustível atual (CUSTOS + VEÍCULO).
- Permissões obrigatórias: notificação, sobrepor, acessibilidade, bateria.
- Toque na compacta NÃO recolhe ao selo (toque fora também NÃO recolhe).


================================================================================
2. FLUXO (ROTEIRO DE USO)
================================================================================

2.1 Abrir o app
    Permissões ok? → tema (escuro / claro / celular) → monitoramento + selo + notificação
    Permissões faltando? → Config > APP (permissões) até completar

2.2 Sem oferta
    Selo flutuante + notificação: "Monitorando ofertas" + Abrir App + Desligar App
    Compacta escondida. Menu fechado.

2.3 Oferta chega
    Compacta aparece (3 linhas, borda da classificação)
    Notificação passa a mostrar o resumo da oferta
    Motorista decide na Uber/99/inDrive (Aceitar/Recusar da PLATAFORMA)

2.4 Recusou ou expirou
    Compacta some em 2 segundos → volta ao selo
    Notificação: manter o último resumo até a próxima oferta
      (se você preferir voltar a "Monitorando", marcar em 6.1)

2.5 Aceitou (detectado pelo Gestor)
    Compacta some em 4 segundos → selo
    Grava histórico na aba da plataforma
    Notificação: resumo da corrida aceita até a próxima oferta

2.6 Selo
    Toque = abre / fecha o MENU ao lado do selo
    Arrastar até o X na base = esconde o selo; monitoramento e notificação continuam
    (reabrir: notificação "Abrir App" ou abrir o app)

2.7 Menu
    Histórico | Calibrar | Custos | Usuário | Dashboard (Pro) | Configurações | Fechar
    Fechar = caixa Cancelar / Fechar (encerra monitoramento)

2.8 Histórico
    Abas Uber | 99 | inDrive  (setas, deslize ou toque no rótulo)
    Cards. Toque no card = seleciona a corrida (detalhe já está no próprio card)
    Embarque / Destino = mapa escolhido (Maps ou Waze), só se houver endereço
    Limpar histórico = confirmação

2.9 Config pelos atalhos
    Usuário  → aba VEÍCULO
    Custos   → aba CUSTOS
    Calibrar → aba CALIBRAR
    Configurações → aba APP (permissões, tema, navegação, enviar log)

3.2 COMPACTA (overlay no mapa, só na oferta)       origem: A + C
--------------------------------------------------------------------------------

Posição: topo, não cobrir Recusar da 99.
Borda: 5 dp na cor da classificação (ruim vermelho / regular laranja /
boa verde / ótima azul). Sem oferta não aparece.

  $/Km = R$ por quilômetro (classificação)
  Lucro = valor da oferta − gasto de combustível estimado     (no lugar de R$/hora)
  Gasto = R$ do combustível estimado                          (no lugar de R$/min)
  Consumo = litros estimados  → linha de baixo, junto de km e tempo
  Nota = nota do passageiro

┌──────────────────────────────────────────────────────────┐
│  $/Km          Lucro           Gasto           Nota      │  ← cinza, pequeno
│  R$ 2,38       R$ 32,10        R$ 5,90         4,9       │  ← branco, grande
│  U   0h28m   16,0 Km   1,2 L   1 Parada(s)               │  ← cinza, médio
│                                    ↑ consumo estimado    │
└──────────────────────────────────────────────────────────┘
     borda grossa = classificação

Toque na compacta: não faz nada (não abre menu, não some).
Toque fora: não some.
Some sozinha: 2 s (expirou/recusou) ou 4 s (aceitou).

================================================================================

6.1 Depois que a compacta some, a notificação:
    [ ] A) fica com o resumo da última oferta até chegar outra
    [ ] B) volta para "Monitorando ofertas"

6.2 Botões Embarque / Destino na COMPACTA (além do histórico):
    [ ] sim, se houver endereço
    [ ] não, só no histórico (compacta fica magra)

6.3 Destino quando há parada:
    [ ] mostrar parada(s) E destino (todas as pernas)
    [ ] mostrar só a próxima perna

6.4 Tamanho do selo:
    [ ] ~60 dp (um pouco maior que a Beta)
    [ ] manter 52 dp
    [ ] outro: ______ dp

6.5 Tema 2.0:
    [ ] escuro agora, opções claro/celular na aba APP nesta versão
    [ ] só seguir o tema do celular por enquanto

6.6 Config em lista + botão Ajuda (estilo loja):
    [ ] nesta 2.0
    [ ] deixar para um recorte depois (manter abas atuais)

6.7 Histórico: toque no card
