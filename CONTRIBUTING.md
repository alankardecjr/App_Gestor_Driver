# Como contribuir

Obrigado por querer contribuir com o Gestor Driver.

## Como colaborar

1. Faça um fork do repositório.
2. Crie uma branch para sua mudança.
3. Implemente a alteração com foco em clareza e qualidade.
4. Teste o que foi alterado.
5. Abra um pull request com descrição objetiva.

## Padrões recomendados

- use commits claros e descritivos;
- mantenha o código simples e legível;
- priorize testes quando possível;
- documente mudanças importantes;
- evite alterações dispersas em uma mesma PR.

## Estrutura de branches

- main: versão estável;
- feature/*: novas funcionalidades;
- fix/*: correções;
- docs/*: melhorias de documentação.
